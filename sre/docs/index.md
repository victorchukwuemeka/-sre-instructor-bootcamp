# Site Reliability Engineering — Training Course

**Duration:** 44 Contact Hours | **Audience:** NIIT Fortesoft | **Context:** Union Bank of Nigeria

---

## Course Overview

This course covers the full Site Reliability Engineering discipline — from foundational principles through to advanced Kubernetes reliability patterns and a capstone project.

## Modules

| Module | Title | Hours |
|--------|-------|-------|
| 1 | Introduction to SRE | 6 |
| 2 | Service Level Management | 8 |
| 3 | Toil Elimination & Automation | 8 |
| 4 | Monitoring & Observability | 8 |
| 5 | Incident Management & Response | 8 |
| 6 | Advanced SRE & Capstone | 6 |

## Learning Outcomes

By the end of this course, participants will be able to:

- Define and calculate SLIs, SLOs, SLAs, and error budgets
- Implement multi-window burn rate alerting
- Design and operate a complete monitoring stack (Prometheus, Grafana, OpenTelemetry)
- Automate toil elimination using Python, Ansible, Terraform, and GitOps
- Run incident response using the Incident Command System
- Write blameless post-mortems with actionable follow-through
- Design and execute Game Day chaos experiments
- Configure Kubernetes reliability patterns (PDB, topology spread, probes, priority)
- Build a complete SRE framework for a banking service

## Course Materials

- Each module contains lecture content, worked examples, and code samples
- Lab exercises are available in the `sre-labs/` directory
- All examples are contextualised for Nigerian banking
